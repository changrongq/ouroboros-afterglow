## 二 · E-24：三字段编码 + 措辞分开

### E-24-1 / E-24-2

```text
形状：excluded : True|False|None
      excluded_undetermined : bool
      reason : string

不变量（三者同时，不得两两）：
  excluded is None
    ⇔  excluded_undetermined is True
    ⇔  reason ∈ UNDETERMINED_REASONS
       = {NO_ALTERNATIVES_REGISTERED, PATHWAY_NOT_CONTROLLED}
```

**check_e21_invariant 现在查四项：**

```text
① 类型：excluded ∈ {T,F,None}；另两字段类型
② 两字段：is_none == INDETERMINATE          （E-21-1，保留）
③ 第三字段：is_none == excluded_undetermined（E-24-2）
④ reason：is_none == (reason ∈ 判不出原因集)  （E-24-2 的第三项）
```

⚠ **实现时我发现一个自己漏的地方，见 §五 · 错误 A。**

### E-24-3：两种措辞

```text
UNDETERMINED_WORDING = {
  NO_ALTERNATIVES_REGISTERED: "该夹具未登记任何替代解释，因此无法判定是否已排除",
  ALTERNATIVES_NOT_ALL_EXCLUDED: "已登记的解释中尚有 {n} 条未排除",
}
wording_for(reason, n_unexcluded=0)
```

**T-12 ③ 的反向断言：**

```text
assert "未排除" not in w1
⇒ 「没登记」的措辞里不许出现「没排掉」的语义词。
⇒ 这条是防合并的：两个 reason 各有措辞还不够，
   若两条措辞都含「未排除」，读了还是分不清。
```

**并且 `wording_for` 遇到未登记 reason 必须抛 KeyError：**

```text
⇒ 不许给默认措辞。默认措辞会把「新增一种判不出但忘了改报告」
  变成「措辞看起来正常」。
```

### E-24-4
