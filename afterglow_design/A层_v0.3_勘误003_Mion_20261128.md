## 四 · E-16 · `INDETERMINATE` 的 scope 进【返回结构】

**Coder 的建议：**

> CROSS-6，并建议三重限定写进返回结构而非仅报告正文。

**采纳，理由与 C-2 同源：**

```text
C-2 要求否定式按四层标（内存 / 序列化 / 下游 / 报告），
而 L3（下游）本阶段不可验。
⇒ 若 scope 只写在报告正文（L4），那它在 L1（返回值）里根本不存在，
  下游拿到的就是一个裸的 INDETERMINATE。
⇒ 所以 scope 必须进返回值。
```

**条款：**

```text
E-16-1  INDETERMINATE 的返回值本身必须含 scope 字段：
          { scope: { this_run: true, this_fixture: <id>, this_readout: <id> } }
E-16-2  只有 scope 三项齐全的 INDETERMINATE 才可被接受；
        缺项的按实现错误处理。
E-16-3  报告正文里的三重限定，是从返回结构抄过去的，不得另起一套措辞。
```
