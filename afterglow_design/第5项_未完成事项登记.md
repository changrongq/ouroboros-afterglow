## 五 · 证据状态三态（2026-11-27 已实现）

**依据**：知微 2026-11-27「总判定建议」。

```text
EVIDENCE_COMPLETE  exit 0   固定预期清单非空、基线有效、
                            明细按 ID 与清单一一对应、每个登记项均 CAUGHT
EVIDENCE_FAIL      exit 1   有 MISSED / INVALID / TEST_DID_NOT_RUN /
                            TEST_CRASHED / TARGET_ERRORED / NOT_ATTRIBUTABLE
                            有失败又有未决时，失败优先，两类明细均保留
EVIDENCE_PARTIAL   exit 2   无失败但有 UNRESOLVED，或应跑项缺失
                            不签全项 PASS
```

**已修的一处真缺陷（知微指出）**：

```text
原 `bad` 计数含 MISSED / INVALID / TEST_DID_NOT_RUN / TEST_CRASHED /
NOT_ATTRIBUTABLE，【漏了 TARGET_ERRORED】。
⇒ 目标 case 抛异常时 verdict 仍是 PASS、exit 0。
⇒ 现 TARGET_ERRORED 计入失败，并印在分类计数里（原先 JSON 有数、终端看不见）。
```

**验收对照**：`test_evidence_state.py`（8/8）
覆盖知微要求的五组：全捕获 / 仅目标异常 / 仅未决 / 异常与未决混合 / 漏一登记项，
另加空清单、六种失败状态逐一、以及「若漏计 TARGET_ERRORED 则 ES-2 会变 PASS」的反证。
