## 一 · 被引用的第一处：一把尺子选出了什么

**引用位置**：A 层 v0.3 §2.2「为什么用布尔不用分数」。

```text
沙盘里的实验（遗传算法进化一维元胞自动机规则，
评分函数 = final + 0.1 × peak，即奖励"能活下来"）：

  规则        形态            得分
  Rule 0      全死             0.0
  Rule 90     分形            15.2
  Rule 30     混沌            21.5
  Rule 110    图灵完备        22.0     ← 唯一"能计算"的
  Rule 184    交通流           3.3
  Rule 255    全活            45.1     ← 冠军

进化收敛到 Rule 251 / 255（种群 42%），拿满分 45.1。
Rule 251 的基因表：8 个模式中 7 个输出 1，只有 010 输出 0。
```

```text
⇒ 那一轮的结论句（原文）：
   「如果我按这个尺子选择，我会淘汰掉整个项目里唯一『能计算』的规则。」

⇒ 这是 A 层 §2.2 采用【合取而非打分】的理由：
   打分需要尺度，而尺度可被优化。
```

## 二 · 被引用的第二处：静默上限丢掉了什么

**引用位置**：C-3「若选丢弃超限，必须同时报出丢弃了多少」。

```text
沙盘里的形状识别代码有一个上限：max_size = 8，
大于 8 个细胞的连通块【直接丢弃】，不报错、不计数、不标记。

后果：连续六个实验里「最大结构永远是 8」，
      被当成了世界的性质，其实是过滤器。

去掉上限重跑（同一世界，60×40 / 80 步 / seed=42）：
   max_size   实体数   最大块边长   长寿且移动
          8     1874            8        14
         16     2361           16        14
         64     2706           64        14
       无上限     2722          326        14
```

```text
⇒ 两个结果要分开说：
   · 干净的那半：去掉上限对【长寿且移动】这个量【没有影响】（14 → 14）。
   · 不干净的那半：确实丢掉了 848 个块，最大块从 8 涨到 326。
     它恰好不改变这个指标 —— 但改不改变别的指标，未测。
```

## 三 · 还有一处间接支撑：形状周期与追踪

```text
沙盘里另有一个对照，A 层没有直接引用，但 §5 的「机制 vs 输入」判据
在方法上借用了它的形式（移除某物后看剩余差异）：

  手放一只滑翔机进生命游戏：
    周期匹配窗 K=1  ⇒ 41 个实体，最长寿命 1 帧，认不出
    周期匹配窗 K=4  ⇒ 4 条相位链，寿命 11，净位移 10，认出

  ⇒ 教训：匹配规则隐含了「形状周期 = 1」这个假设，
    而滑翔机的周期是 4。于是"看不见"被读成了"不存在"。
```

```text
⇒ A 层 §5 借用的是这个形式：把某个来源移除后，看还剩不剩差异。
   但 A 层的判据与这个实验没有依赖关系 —— 它只是形式相似。
```
