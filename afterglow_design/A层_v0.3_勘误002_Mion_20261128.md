## 一 · E-7 · `C-1` 在 A3 上的状态：新增第三态

```text
C-1 在 A3 上的适用性 = NOT_TRIGGERABLE_BY_TYPE
```

```text
释义：C-1 要求"处理多条证据的情况"。
      而本版 source_ref 的类型是【单个可空字符串】，
      ⇒ "A3 上出现多条引用"这条输入【不可构造】。
      ⇒ 空的是【输入域】，不是【实现】。
```

```text
⇒ 它既不是"设计约束"（不是我们决定不让它出现），
   也不是"暂未实现"（不是打算以后做）。
   是【类型决定了这条输入不存在】。
```

**硬约束：**

```text
C1-TYPE-1  若 source_ref 类型由「单值」改为「列表」，
           则 C-1 在 A3 上立刻 APPLICABLE，A3 必须按 C-1 重审，
           不得沿用本版窄口径。
C1-TYPE-2  A3 那格报告必须同时写：
             match     = NOT_COVERED
             multi_ref = NOT_TRIGGERABLE_BY_TYPE
```

## 二 · E-8 · `CROSS-6` 与 `INDETERMINATE-SCOPE`

```text
CROSS-6    「夹具复现了某个出口」不构成「该情形在真实系统中存在」。
```

```text
INDETERMINATE-SCOPE
  B 层触发的 INDETERMINATE，只支持这一句：
      「本判据在此次夹具下，复现了该未定出口。」

  不支持：
      ✗ 真实情况确实未定
      ✗ 该机制无法判定
      ✗ 任何关于真实历史 / 真实模型的推断

  每一处 INDETERMINATE 必须带三重限定：本次 / 该夹具 / 该读出
```

**⇒ CROSS 系列由 5 条扩为 6 条。来源：Coder 回执 §五。**

## 三 · E-9 · `B-SCOPE-1..3`（**报凌翼核定中，未生效**）

```text
B-SCOPE-1   B 层允许实现【最小判定层】，只实现 A 层已定义的字段：
              admitted / per_rule / origin_attribution / unknowns / reason_summary
              B3-OBS / B3-CLAIM / B4 / MECH / EXCLUDED
              INDETERMINATE / NOT_COVERED
            不得实现任何未在 A 层定义的字段或逻辑。

B-SCOPE-2   该判定层不得包含：任何重要性评分、排序、学习器、真实历史读取。

B-SCOPE-3   该判定层是 B 层测试的【前置】，不是 B 层的成果。
            报告不得把"判定层已实现"写成"记忆机制已验证"。
```

**状态：`AWAITING_RULING_LINGYI`。**

```text
⇒ 理由：凌翼裁定二授权的是"为合成夹具编写最小失败条件测试"。
        不建出待测对象就没法写测试，所以我判断"最小判定层"落在授权内。
        但这是【对授权的解释】，不是授权本身。
⇒ 故明列三条，交凌翼核。若判定越界，B 层立即停。
```

## 四 · E-10 · 第一批清单由 6 条扩为 8 条

```text
新增（均来自 Coder 回执 §二）：

T-5c   用 delta=None 的夹具，若实现写成 `delta != 0`，必须抛错或走错分支
       ⇒ 把"实现错误"变成"测试红"

               不能证明【下游没人把它当 0 用】。

       ⇒ 理由：没有这条，T-6a 可以用「EXCLUDED 恒 False」通过。
```

```text
⇒ 第一批 = T-1, T-2, T-3, T-4, T-5, T-5c, T-6, T-6e = 8 条
```
