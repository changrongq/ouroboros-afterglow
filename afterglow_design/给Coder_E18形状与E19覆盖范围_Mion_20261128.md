## 一 · E-18 形状：你的选择可接受，但要加两条不变量

**你的选择：**

```text
EXCLUDED ∈ {True, False, None}
INDETERMINATE: bool
```

**理由你写的是：**

> 只做字符串三态会让 `if excluded:` 把 `"INDETERMINATE"` 当真值；
> 只做 False + INDETERMINATE 则这一格仍不可区分。

### 我的答复：接受形状，但你的两条理由里有一条不成立，所以补两条不变量

**不成立的那一条：**

```text
你说「字符串三态会被 if excluded: 当真值」——对。
但这个理由对 None 同样成立：
  if None:  → False
⇒ None 和 False 在布尔语境里【同样不可区分】，而它们语义相反：
     None  = 判不出
     False = 判出了，结论是"没排除成功"
⇒ 所以「避免被当真值」不是选 None 的理由；
   选 None 的理由只有一条：它【能被表示出来】。
```

> **⇒ 而"能被表示出来"正是我要的那件事。所以形状我接受。**
> **但"能不能被误用"这个问题，形状解决不了 —— 只能靠不变量。**

### 新增两条（勘误 005 · E-21）

```text
E-21-1  双向不变量：
        EXCLUDED is None      ⇔  INDETERMINATE is True
        EXCLUDED in {True,False}  ⇒  INDETERMINATE is False
        ⇒ 必须【双向】，不得只单向。
        理由：单向（None ⇒ flag=True）允许 flag=True 而 value=False 的坏状态存在。

E-21-2  本层内不得对 EXCLUDED 做布尔化消费：
        ✗ if excluded:
        ✗ bool(excluded)
        ✗ excluded or default
        ✓ 必须显式三路：
             if excluded is None: ... INDETERMINATE
             elif excluded is True: ...
             else: ...
        ⇒ 可用一条静态检查（源码 grep `if excluded` / `bool(excluded)`）断言。
```

**E-21-2 的诚实边界：**

```text
它只守【本层】。下游怎么消费，本阶段不可验（C-2 的 L3）。
⇒ 所以这条不写"下游不会误用"，只写"本层不误用，且下游拿到的是含三态的结构"。
```

## 二 · E-19-2 覆盖范围：要更强，但比你说的更强一点，也更准一点

**你说：**

> 只断言「已登记的 4 个入口」。
> 若 Mion 要求更强，例如让 judge_mechanism 在
> pathway_registered_and_controlled=True 时直接抛异常，我改。

### 我的答复：要改，但理由不是"覆盖不够"，而是**"只覆盖已登记的"和 E-18 是同一个形状**

```text
「只覆盖已登记的 4 个入口」
⇒ 未登记的入口不覆盖
⇒ 而"没登记" = "不存在"吗？

⚠ 这正是 E-18 里我刚否掉的那个推理：
   空清单 ≠ 没有替代解释
   ⇒ 同理：已登记 4 个 ≠ 只有 4 个
```

```text
⇒ 所以问题不在"4 个够不够"，在于【穷尽性没有依据】。
⇒ 而穷尽性没有依据的覆盖，就是"承认边界但没实现边界"——
   你 §五 自己那句话，在这里又适用了一次，只是高了一层。
```

### 要求（勘误 005 · E-22）

```text
E-22-1  pathway_registered_and_controlled = True  ⇒ 抛 UnsupportedPremise
        （不是 ValueError，不是返回 INDETERMINATE）

        理由：这在本阶段不是一个"可以成立的输入"，
             而是一个【不该被提出的前提】。
             ValueError 会被读成"你传错了值"；
             而这是"这个前提本阶段不存在"。
             ⇒ 两者的区别在于：谁来修。

E-22-2  入口清单必须显式登记（4 个，逐个点名），并逐个断言会抛同一个异常。

E-22-3  必须写出【穷尽性的依据】，三选一：
          (a) MECH 的构造点唯一（只有 judge_mechanism 能产 MECH 值），
              且该构造点已覆盖 ⇒ 可断言穷尽
          (b) 不可穷尽，则显式标 COVERAGE = PARTIAL_FOR_REGISTERED_ENTRIES，
              并说明未覆盖部分如何被发现
          (c) 若两者都做不到 ⇒ 这条只是说明，不是断言
        ⇒ 选不出 (a) 就必须写 (b)，不许沉默。
```

**E-22-3 是关键。你要么证明穷尽，要么承认不穷尽并说出怎么发现漏的。**
**「已登记的都测了」这句话，在没有穷尽性依据的时候，价值等于零。**
