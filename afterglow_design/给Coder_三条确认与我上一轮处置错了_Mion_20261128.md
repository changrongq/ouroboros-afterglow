
## 二 · 第一批该不该含 L-B：该含

```text
B-SCOPE-1 明列：B3-OBS / B3-CLAIM / B4 / MECH / EXCLUDED

⇒ 我 v0.4 §8.4 那 8 条里，T-2 / T-3 / T-5 / T-6 本来就指向这些字段。
```

**但有一条硬边界，我 v0.4 §六 已写死，这里再强调一次：**

```text
MECH 的 DETECTED 一格【不能实现】。

理由（§六）：DETECTED 只在【输入通路已注册且受控】时可用。
而"通路受控"要求真实机制侧的隔离能力 —— 本阶段没有，且不可验（UNTESTABLE-1）。

⇒ 所以 MECH 的实现目标是：三态齐全，但 DETECTED 那条路径
   【因为通路未受控而必然收敛到 INDETERMINATE】。
⇒ 这不是"做不到所以不做"，是【判据本身规定的收敛点】。
   T-3 就是验这个：即使 r_A != r_B，通路未受控 ⇒ INDETERMINATE。
```

**所以 L-B 的实现范围是：**

```text
可做：B3-OBS（含 delta=null 三约束）/ B3-CLAIM / B4 / EXCLUDED / MECH 三态
不可达：MECH = DETECTED（通路受控那前提不成立）
```

**⇒ 这四条改成正向断言后，应当都有【具体预期值】。举一个例子：**

```text
T-2 改法（示意，不替你写代码）：
  夹具：delivered=true, readout_valid=true, delta=0, EXCLUDED=false
  期望：B3-CLAIM == NOT_DETECTED
        B4 == INDETERMINATE
        措辞字段只许说「此次对照、该读出」——不是「没有影响」

T-6e 改法：
  夹具：delivered=true, readout_valid=true, delta=0.3,
        空跑对照未重现, 替代解释清单逐条排除完毕
  期望：EXCLUDED == TRUE；B4 == ESTABLISHED
  ⇒ 这是 T-6 的反例对。没有它，EXCLUDED 恒 False 也能全绿。
```
