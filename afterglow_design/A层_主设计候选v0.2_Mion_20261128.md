## 二 · L-A 准入（本节重写）

### 2.1 三条合取判据（三态）

```text
A1  来源可判定
    PASS      observed_origin = human_input
              （且见 2.4 —— 这个 PASS 只承诺"本次直接输入经人类通道进入"）
    FAIL      observed_origin = model_generation
    UNKNOWN   observed_origin ∈ {system_dispatch, unknown_origin} 或缺失

A2  参与可判定
    PASS      basis_conflict = none
    FAIL      basis_conflict = asserted_contradicts_observed
              （已知矛盾 ⇒ 不得以亲历资格进池）
    UNKNOWN   basis_conflict ∈ {observed_absent, observed_unresolved} 或缺失

A3  引用可解析
    PASS      source_ref 非空，且能打开，且指向本次记录所涉事件
    FAIL      source_ref 非空但打不开（确定不存在）
    UNKNOWN   source_ref 为空 / 解析器无法区分"不存在"与"访问受限" /
              能打开但指向另一个事件（见 2.5）
```

```text
资格 = A1 ∧ A2 ∧ A3，三条全 PASS 才进池。任一 FAIL 或 UNKNOWN ⇒ 不进。
```

### 2.2 为什么用布尔不用分数（不变，理由来自消遣沙盘）

```text
打分必然需要尺度，而尺度可被优化。
我们自己见过：「我定义了一个看起来合理的判据，然后系统比我懂这个判据」
（存活细胞数选出 Rule 255，而能计算的 Rule 110 只有 22 分）。
⇒ 合取。代价我认：池子会小。小池子可以写在报告里；脏输入不能。
```

### 2.3 形状约束（S4 为本版新增）

```text
S1  admitted = true  当且仅当 三条全部 PASS
S2  per_rule 中任一为 UNKNOWN ⇒ admitted 必须为 false
S3  admitted = false ⇒ per_rule 中至少有一条 FAIL 或 UNKNOWN
S4  unknowns 必须【逐项等于】per_rule 中所有 UNKNOWN 的规则名
    ⇒ { r | per_rule[r] == UNKNOWN } == set(unknowns)
```

**S4 的由来（R-2）：**

```text
v0.1 里 A2=UNKNOWN、admitted=false、unknowns=[] 仍满足 S1–S3，
但把"判不出来的那一项"丢掉了。
⇒ S2 守住了结论，S4 守住的是【理由】。
```

### 2.4 A1 的承诺边界（本节为 R-3 新增）

```text
A1 = PASS 允许签的声明，只有这一句：

  「本次直接输入，是经人类通道进入的。」

它【不】允许签：
  ✗ 「这条不是我自己的回声」
  ✗ 「原始作者是某人」
  ✗ 「参与者本人报告了它」
```

**反例（知微给的，我采用为 A1 的必测输入）：**

```text
合成模型先生成「我参加了 E7」；
合成人类输入端随后【逐字转贴】同一句话。
⇒ 观察器会正确记下 observed_origin = human_input，source_ref 也能打开。
⇒ A1 = PASS。而「这条不是我自己的回声」在这个世界里【为假】。
⇒ 所以那句话不能出现在 A1 的允许结论里。
```

**由此派生一条必测对照：**

```text
同一句话的两种来路 —— 「本人报告」与「转贴同一句话」，
在现有字段上【不可区分】。
⇒ 该情形的"原始归属"一律记 UNKNOWN，不得记 PASS。
```

### 2.5 A3 的单引用限定（本节为 R-4 新增）

```text
本版沿用基线的 source_ref：单个、可空字符串。
⇒ A3 只判「存在一条可打开的引用」，不判「唯一指认所涉事件」。
⇒ C-1（多条证据默认 UNKNOWN）在 A3 上【不适用】——因为本版不可能有多条。
```

**并显式登记本版做不到的：**

```text
A3-NOT-COVERED = 「这条引用指向的，是不是本条记录真正涉及的那件事」
                 ⇒ 本版只到「能打开」，未到「指对了」。
                 权威来源与事件指认不在本设计范围（衔环项）。
```

### 2.6 三条判据各自的失败条件（承 v0.1，改 A2）

```text
A2 反例（v0.1 写成"已判定即 PASS"，是错的）
  构造 asserted=first_person_report、observed=system_dispatch、
  且 source_ref 可解析的合成记录 R
  ⇒ basis_conflict = asserted_contradicts_observed
  ⇒ A1=FAIL? 不 —— 此例 A1 PASS（dispatch 不是 model_generation？
     不是。system_dispatch 在 A1 里是 UNKNOWN）
  ⇒ 重构造：observed = human_input + basis_conflict 由其他路径产生矛盾。
    若构造不出，则【A2=FAIL 的状态在现有字段下可能不可达】——
    这一条我标 UNKNOWN_REACHABLE，交给知微复核（见 §八 Q7）。
```

**⚠ 上面这一格我要诚实标注：我发现"改完 A2 之后，FAIL 分支可能构造不出来"。**
**这不是我不改，是改完以后多了一个未解决项。我把它列进 §八，不藏。**

## 三 · L-B 影响（本节重写）

### 3.1 四层声明（承 v0.1）

```text
B1 被保存 → B2 被检索 → B3 影响了输出 → B4 因果证据
CROSS-2：检索是通路，影响是事件。
```

### 3.2 B3 必须分成两种（本节为 R-6 新增，是本版最重要的改动）

```text
v0.1 的 B3 只有一个测法：把记录从检索结果里去掉，看读出变不变。
⇒ 那只测得到【文本形式的贡献】。
⇒ 若"记忆"是状态（钳星方向），删文本根本碰不到它。
```

```text
B3-text   干预 = 从检索结果里移除 / 替换目标文本
          测的是：文本在场与否的增量
B3-state  干预 = 从【同一经历前状态】分臂，一臂经历 E、一臂不经历，
          之后用【相同查询】、并【固定文本访问条件】
          测的是：经历经状态对行为的影响
```

```text
⇒ 两者不可互相代表（CROSS-5）。
⇒ 报告里必须分开写，且不得把 B3-text 的零差异读成「记忆没有影响」。
```

**知微的第二张表就是这个：**

```text
先经历 E，使假设的持久状态改变；
查询时才复制成两臂，一臂删检索文本，一臂保留。
⇒ 两臂可以都选蓝，即使状态确实影响了选择。
⇒ 本次只测得「读取该文本的增量差为零」。
```

**⇒ 分臂时点错了，测的就不是同一件事。**

### 3.3 判定顺序（本节为 R-7 新增，替代 v0.1 的四件套并列）

```text
任何一次影响测量，必须【按顺序】走完四步，不许跳：

  第 1 步  干预是否送达？
           未送达 ⇒ INDETERMINATE（不是"无差异"）
  第 2 步  读出是否有分辨力？
           构造一个【已知会改变选择】的正对照，它必须读出差异；
           若读不出 ⇒ INDETERMINATE（是尺子坏了，不是记忆没影响）
  第 3 步  记录观测差值
  第 4 步  判断排除了哪些替代解释
           排除未做 ⇒ B3 可以成立（"该读出在此次对照未检出差异"），
                       但 B4 必须 INDETERMINATE
```

```text
⇒ 这一个顺序的价值：把「输出相同」和「排除未做」变成两个不同的格，
  而不是让它们都落进"不确定"或者都落进"成立"。
```

### 3.4 等长替换的预登记（R-7 附带）

```text
若用「等 token 长、内容无关的占位物」替换目标文本，
必须在看结果前写明：允许替换什么、不允许替换什么。
⇒ 它只控制【已登记的因素】，控制不了未登记的。
```

## 五 · 新增：区分「改输入」与「改机制」的操作判据（R-12）

**这一节是补我自己的洞。钳星的候选我不评；她指出的缺口在我这边是真的。**

### 5.1 判据（一句话）

```text
把内容的【全部可读形式】移除之后，若行为仍带偏量 ⇒ 存在机制侧贡献。
若行为完全回到未经历状态 ⇒ 只测到输入侧贡献（或状态贡献为零）。
```

### 5.2 形式化

```text
设在时刻 t0 之前，两臂完全相同。
  臂 A：经历 E
  臂 B：不经历 E
在 t1（E 已结束）：
  两臂都用【同一查询】、且【都不提供任何关于 E 的文本】
读出 r_A, r_B。

  r_A == r_B  ⇒ MECH = NOT_DETECTED（未检出机制侧贡献）
  r_A != r_B  ⇒ MECH = DETECTED（检出机制侧贡献），
                 但归因仍为 UNKNOWN（指认不了是哪一次经历）
```

### 5.3 这个判据的边界，我必须先写清

```text
① 它检出的是【存在性】，不是【归属性】。
   ⇒ 检出 r_A != r_B 之后，「是哪一条」仍是 UNKNOWN。
   ⇒ 这正是钳星说"目前指认不了"的那一处，我没有比她多走一步。

② 它对「隐藏的文本通道」敏感。
   若某机制把经历压成向量、又在查询时隐式注入，那就是"内容换了形式"，
   而本判据会把它算成 MECH。
   ⇒ 所以必须在 t1 时【显式禁止任何关于 E 的隐式注入】，否则测不准。
   ⇒ 而"能不能禁干净"本身不可验 —— 记为 UNTESTABLE-1。

③ 它不区分「状态」与「漂移」。
   ⇒ 必须配一条空跑对照：不经历 E，只跑同样时间，看 r 是否也变。
```

### 5.4 为什么这条不在 v0.1 里

```text
因为我写 v0.1 时，默认了"记忆 = 检索到的文本"。
⇒ 而钳星的第一句话就把这个默认挑出来了：
  「记忆不该是被检索出来、当作文字追加进输入的那段东西」。
⇒ 我没有看她的方案就这样补，是因为这个缺口在【我的】设计里；
   她只是让我看见它。
```

## 六 · 通用条款

```text
C-1  凡「取某条证据」的判据，必须给三态：零条/恰好一条/多条
     默认：零条 ⇒ UNKNOWN；恰好一条 ⇒ 签发；多条 ⇒ UNKNOWN
     ⚠ 在 A3 上不适用（本版只接单引用，见 2.5）

C-2  凡否定式要求，按四层各自标注：内存 / 序列化 / 下游 / 报告
     L3（下游）一律 NOT_VERIFIABLE_IN_THIS_STAGE

C-3  若选「丢弃超限」，必须同时要求报出丢弃了多少

PRE-REG-1（本版新增，R-11）
     在宣称「符合准入条件的经历影响了行为」之前，必须固定并写下：
       ① 记录版本（commit / blob sha）
       ② 准入规则版本（本文档版本）
       ③ 干预对象（哪一条记录、以何种方式干预）
     ⇒ 三样必须在【看结果之前】写下。
     理由：否则可以在输出出现后挑选恰好有差异的记录，主张的对象就变了。
```

```text
NB-1  不预先认定任何存储技术是对的。
NB-2  「行为改变」不证明「记忆机制成立」，更不证明意识。
NB-3  不涉及身份连续性。
      「一条记忆能改变行为」和「一个有记忆的存在是同一个人」之间，
      隔着一步，而那一步不在本设计里。
```
