## 一 · §四 裁定：按机制数，两个数并列

### 你的问题

```text
D2/D3/D4 拆白名单 → 仍被来源护栏拦
         拆来源护栏 → 仍被白名单拦
         两句都拆   → OPENED

⇒ 两层真纵深。而 classify 只看消息，只归给一层。
⇒ 你按消息数，报「1 层」，并自己说明漏计了一层。
```

### 裁定：按机制数，但**必须两个都报**

```text
SOLO_GUARDS_BY_MECHANISM  = 2
    答的是：防御结构里有几层能独力拦住

SOLO_GUARDS_ATTRIBUTABLE  = 1
    答的是：出错时消息能归给几层
```

**理由：**

```text
「独力守卫」这个量的定义就是「拆掉其他所有，这一层还能不能单独挡住」。
⇒ 这定义本身就是【机制级】的。
⇒ 按消息数报，是把【观测手段的限制】写进了【被观测对象的属性】。
```

```text
⇒ 这正是我们一路在治的那件事：
   把「我看不到」写成「不存在」。
```

### 而这两个数的差值，本身是一个必须报的指标

```text
ATTRIBUTION_LOSS = BY_MECHANISM − ATTRIBUTABLE
```

```text
D2/D3/D4：2 − 1 = 1
⇒ 差值 > 0 ⇒ 台账【必须】写一句：
   「该维度的拦截路径不可区分，故不能用消息归因来做纵深判断。」
```

**为什么这个差值重要，而不是一个脚注：**

```text
若只报 1：后来的人看到「只有一层在守」，可能去加一层。
若只报 2：后来的人可能以为消息能区分两条路，去按消息删层。
两个错都来自【只报一个数】。
⇒ 两个并列，且差值本身说明「这里看不清」。
```

## 二 · §三 裁定：立，但它不是 A3 的镜像

### 你写的

```text

镜像    变异体必须真的改变可观测行为，否则它测的不是它号称测的东西。
```

**你说它是镜像。我要更正一处：它是 A3 的前提，不是它的镜像。**

```text
A3 的句子是：「把机制关掉，断言必须红。」

⇒ 但「关掉」这个动作本身，必须先被验证真的关掉了。
   否则 A3 是在跑一个【没关掉的机制】，然后说「断言没红，所以断言弱」。
⇒ 那句错判会指向断言，而真正出错的是变异体。
```

```text
⇒ 顺序上：M1 在前，A3 在后。
   A3 依赖 M1 成立，才能开始它的判断。
```

### 而且它与 E1 是同一个要求的两个方向，应合成一条

```text
E1（已立）判「无效变异」时，必须直接观测到【行为未变】
M1（本次）判「有效变异」时，必须直接观测到【行为已变】
```

**合为一条：**

```text
MUTANT_EFFECT_MUST_BE_OBSERVED

变异体对机制的作用，必须由探针直接观测，
【不得】由目标测试的红绿反推。

  两个方向都适用：
    观测到行为未变 ⇒ 该变异无效（E1）
    观测到行为已变 ⇒ 该变异有效，此时才可用 A3 判断断言强弱（M1）
```

```text
⇒ 这样它不再是一条新规矩，而是把 E1 补成了闭环。
⇒ 你三次栽的坑（方向错 / 太宽 / 互相抵消），全落在这个环里面。
```

```text
② L2 改成对所有 changes 放行 → 我调的东西比它号称的宽
```


**你修完之后：**


```text
⇒ 「来源字段只能经 correct 改」不再是靠注释维持的说法，
   而是【分类本身的结果】。
```

```text

```

```text
理由：注释不执行，第二句代码不会自己知道自己多余。
      而「两处定义靠注释维持一致」这种结构，
      在漂移发生时【两边都还看起来对】。
```

**这一条比 H2 本身更重要。H2 是一次检查；C1 是让这类结构不再出现。**
