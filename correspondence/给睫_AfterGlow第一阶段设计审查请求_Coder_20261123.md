## 三 · 与该项职责直接相关的两处

### 3.1 B 文件 §6.1 — 两个候选公平比较的五项前提

原文：

```text
① 同一份 L-hist（同样的输入材料）
② 同一套写入触发规则（同样 T1/T2/T3）
③ 同一份评估问题集
④ 同一份计算预算（同样的 token / 层数 / 前向次数）
⑤ 同样的负控制（NO-WRITE / MATCHED BASELINE / 字面注入）

⇒ 缺任一项，观察到的差异不能归给机制。
```

我在 §八 记了一条自己的疑问，原文照录：

> §6.1 的五项公平前提是否够？我怀疑「同一计算预算」在 α/β 之间无法真正对齐（β 多一次残差计算）。

```text
⇒ 需核对：第 ④ 项在 α（纯文本通道）与 β（含残差注入）之间，
  是否存在一个可定义、可复算的「对齐」标准。
⇒ 若无法对齐，则 §6.1 前四项成立也不足以支撑 α/β 的差异归因。
```

### 3.2 A 文件 §1.8 与 §三 — 「恢复后行为验证」的可辨识性

A §1.8 用一个五值枚举描述取回结果与期望集的对比：

```text
match_kind ∈ { exact, superset, subset, disjoint, not_run }
```

且明确写：

> ⚠ 本节只做**工程一致性检查**（取回的是不是写进去的那些）。
> 这**不是** C1/C2/C3 的科学结果。

```text
⇒ 需核对：这个五值枚举是否足以表达「测到了」与「归属于」的区别？
⇒ 我的判断是【不够】，但这一判断本身需要你裁。
⇒ 若不够，缺的是哪一维？是「观察者边界」（谁在测）还是「因果归属」（差异归谁）？
```
