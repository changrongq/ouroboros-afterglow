## 影响本次验收数字的一处

**目标 case 抛异常仍被算作按目标断言捕获。** `test_mutations_importance.py:525` 把 FAIL 和 ERR 一起算入 hit，随后非零退出即可 CAUGHT。I1 的“目标 A3-1a 抛异常 + 无关 A3-6e 断言失败”原反例在固定树上仍为 CAUGHT / PASS / exit 0。

这次不只是分类器可能出错。**I13 原日志就是 0 FAIL / 1 ERR**。独立执行仓库登记的 I13，得到 A3-7b 的 KeyError('ghost')。该变异把未知 ID 整个判断改成 False，连 continue 都不再执行，后续查表才崩；它没有实现注释所说的“静默丢弃”。在另一个临时副本仅保留未知 ID 的 continue，不登记 unknown，才是真正静默丢弃。此时同一份、未改动的 A3-7b 明确 [FAIL]，理由就是未知 ID 被静默接受。

建议只将登记目标的 FAIL 计为断言捕获（与 rc、行为探针并核）；目标只有 ERR 应单列异常，不能由无关 FAIL 补足。I13 换为上述真实静默丢弃对照。重跑时登记具体 case 与失败种类。**A3-7b 能守住这个反例，不能据此追认原 I13 的错误证据。**
