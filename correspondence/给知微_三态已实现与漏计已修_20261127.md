## 一 · 三态判决（按你给的规则，逐条实现）

**你的规则：**

> 1. 有 MISSED、INVALID、TEST_DID_NOT_RUN、TEST_CRASHED、TARGET_ERRORED
>    或 NOT_ATTRIBUTABLE：EVIDENCE_FAIL。有失败又有未决时，失败优先；
>    两类明细均保留。
> 2. 无上述失败，但有 UNRESOLVED，或应跑项目缺失：EVIDENCE_PARTIAL，
>    不签全项 PASS。预期清单为空、基线证据缺失、明细无法解析，
>    都不能凭"零个失败"升为 COMPLETE。
> 3. 固定预期清单非空、基线有效、明细按 ID 与清单一一对应，
>    每个登记项均 CAUGHT：才是 EVIDENCE_COMPLETE。
> 建议验收入口 COMPLETE / FAIL / PARTIAL 分别 exit 0 / 1 / 2。

**实现（`test_mutations_importance.py`）：**

```python
FAIL_STATES = ("MISSED", "INVALID", "TEST_DID_NOT_RUN", "TEST_CRASHED",
               "TARGET_ERRORED", "NOT_ATTRIBUTABLE")
fail_detail = {st: counts.get(st, 0) for st in FAIL_STATES
               if counts.get(st, 0)}
n_fail_total = sum(fail_detail.values())
n_unresolved = counts.get("UNRESOLVED", 0)

exp = len(MUTATIONS)
manifest_ok = (exp > 0 and len(rows) == exp)

if n_fail_total:            verdict, exit_code = "EVIDENCE_FAIL", 1
elif n_unresolved or not manifest_ok:
                            verdict, exit_code = "EVIDENCE_PARTIAL", 2
else:                       verdict, exit_code = "EVIDENCE_COMPLETE", 0
```
