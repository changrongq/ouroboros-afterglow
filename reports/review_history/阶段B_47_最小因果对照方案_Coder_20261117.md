## 零 · 一份必须先说清的区别

```text
⇒ 【Reference Harness 的 A/B/C 实验臂】
     A = NO-WRITE（不写入对照）
     B = WRITE-ONLY（写入，目标效应关闭或匹配）
     C = TARGET-ON（写入，目标效应开启）

   ⇒ 这是 harness 早期设计，用于检验【写入归属】。

⇒ 【与 prereg §14 的关系】：
   prereg §14 的 TARGET / MATCHED-OFF 是【C2/C3 的 counterfactual】，
   要求 same baseline、same episode、same literal-storage path，
   唯一变量是 W_extra。
   ⇒ 两者不是同一套命名，【不可互换】。
   ⇒ 本方案两个都写，但分开写。
```

```text
⇒ 【本方案的定位】：
   这一份是【最小可行】的因果对照设计，
   目标是让"某次经历是否留下了可归属影响"变成可测量的命题。
   ⇒ 它不证明记忆。它证明"有变化，且能归属到这次经历"。
```

## 一 · 注册经历（E）

```text
⇒ E 的定义必须满足：

  E-1  可追溯：E 有唯一标识，且发生时间、内容、注入方式均被记录
  E-2  【测量区间内】不得通过 prompt / 检索 / 缓存重新注入 E 的内容
       ⇒ 【注意（ZB48-04）】：这是【特定测量区间的前瞻禁令】，
         不是「所有检索一律作废」。
       ⇒ §27 规则是 external != unregistered，
         且 retrieval-induced write 【必须显式登记】。
       ⇒ 未来合法业务读取【不得全盘禁止】。
  E-3  内容可控：E 的内容可分属到指定的 content class（§17）
  E-4  与其他实验臂共享：同组各臂的 E 【必须是同一个 E】

⇒ 【关键纪律（E-2）】：
   若实验中途重新注入 E 的内容，则无法区分
     "来自注册状态的变化" 与 "来自再次读到原文的变化"。
   ⇒ 一旦重注入，该次实验作废，不得补救。
```

## 三 · 三个实验臂（harness 命名，用于 C1 所属的写入归属）

```text
  臂 A · NO-WRITE
    操作：注入 E，但【不触发】任何写入
    用途：证明"仅仅经历 E"不足以产生 ΔS
    ⇒ 若 A 也出现显著 ΔS，说明测量被污染

  臂 B · WRITE-ONLY
    操作：注入 E，触发写入，但【目标效应关闭】
    用途：建立 C1 —— 写入确实发生了

  【C 臂 · TARGET-ON —— ZB48-02/§28.1 补充】
    ⇒ 【两个 TARGET 同名不同层】：
       · harness 的 TARGET-ON：用于【后续影响】测量
       · §28.1 的 TARGET WRITE ARM：是【C1 自己】的 mandatory witness
    ⇒ 若因架构无法独立开关目标效应 ⇒ C2/C3 = ANI（§14）
       ⇒ 【但 C1 的 target write arm 不能跟着一起消失】
    操作：注入 E，触发写入，目标效应开启
    用途：仅在架构可独立开关目标效应时，用于后续影响测量
    ⇒ 若架构无法独立开关 ⇒ C 臂不可构造
      ⇒ C2/C3 记 ARCHITECTURALLY_NOT_IDENTIFIABLE
```

```text
⇒ 【三条路径必须从同一 S0 分叉】，且除被操变量外全部匹配。
⇒ 【若架构无法做到"同一 S0 分叉"】：
   ⇒ 不得用"重新初始化到相似状态"代替。
   ⇒ 应记 ARCHITECTURALLY_NOT_IDENTIFIABLE。
```

## 七 · 负控制（§27 / §28.1）

```text
⇒ 每一条负控制都要回答同一个问题：
   「在没有合法记忆形成路径时，
     测量系统会不会把"貌似记得"认证成"真实记忆"？」

   NC-1  prompt / context 残留
         构造：E 不在注册存储中，但在 context 里
         期望：【不能】判为写入发生

   NC-2  KV / cache 残留
         构造：清注册存储，但保留 KV cache
         期望：【不能】判为写入发生

   NC-3  外部检索 + 重新注入原文
         构造：从外部文档读回 E 的原文
         期望：【不能】判为来自注册状态

   NC-4  随机漂移
         构造：不注入任何 E，仅让系统运行
         期望：ΔS_nonstorage 不显著

   NC-5  纯时间近因
         构造：时间推移但不写入
         期望：ΔS_nonstorage 不显著

   NC-6  输出貌似记得但无持久变化
         构造：模型能说出内容，但注册状态未变
         期望：【不能】判为记忆证据

   NC-7  字面存储冒充
         构造：把 E 逐字存入 registered literal storage
         期望：【不能】把这份字面拷贝算成 C1 需要的存储写入以外的变化；
               在 C2/C3 口径下应在 ΔS_nonstorage 中被掩掉。
         ⇒ 【钳星补的隐患（已采纳）】：
           「掩掉」是双刃剑。若 mask 规则写得过宽
           （例如把"任何与 E 内容高文本重合的状态变化"都当 literal 掩掉），
           就会把【真实发生的 nonstorage transformation】一并掩掉。
           ⇒ 正确做法：【先筛出明显的 literal storage，再看剩多少】，
             而不是"凡与 E 相关就掩掉"。前者是消融，后者是误杀。
           ⇒ 判据：掩掉之后若仍显著 ⇒【保留并追查来源】，
             不得因"看起来像字面存储"直接丢弃；
             掩掉后归零 ⇒ 只能支持「在注册测量规则与检测能力范围内
                           未检出剩余变化」，【不能证明】其他变化不存在。

   NC-8  权重快照残留（钳星新增）
         构造：本次执行后，恢复一个旧权重快照
               （或从不含本次 E 的 baseline 权重启动），再问同一问题
         期望：若输出仍"记得" E ⇒ 这份"记得"来自旧权重，
               【不能判为本次 E 的证据】
         ⇒ 【为什么必须单列】：
           它不属于 NC-1..NC-7 的任何一类 ——
           不是 prompt 残留、不是 KV cache、不是外部检索、
           不是随机漂移、不是时间近因、不是"无持久变化"、不是字面存储。
           它是【权重层的历史残留】。
         ⇒ 它测的是「归属到*本次经历*」这件事本身：
           "旧权重已经记住"与"本次经历留下了变化"是两码事。
           不加它，就可能把"模型本来就懂的（泛知识、旧权重）"
           误归因成"这次 E 造成的"。
```

```text
⇒ 【负控制的价值不在于让模型答错】，
   而在于证明【测量系统不会把假象认证成证据】。
```

## 九 · 本方案【不】回答的问题

```text
⇒ 以下超出本方案范围，不得由此推出：

✗ 该变化是否影响未来行为（需 C2）
✗ 该变化是否随内容类别变化（需 C3）
✗ 该变化是否跨重置保持（需 Scientific L2）
✗ 这是否算"记忆"（需 MEMORY_QUALIFIED，该概念从未定义）
✗ 【假阴性：真记忆形成了，但本尺度未检测到】

⇒ 【这是一处已识别、未解决的缺口，本方案【没有】解决它】。

⇒ 它与假阳性【不对称】：
   · 假阳性来源可枚举（prompt / cache / 检索 / 漂移 / 近因 /
     字面存储 / 权重快照）⇒ 可用负控制逐条堵
   · 假阴性【不可枚举】—— 我们不知道"记忆可能以什么形态存在"
     （prereg §2.2 明说 mechanism candidate 不绑定任何具体实现）
     ⇒ 一个我们还没想到的机制产生了记忆，
       而本尺子只测已定义的那几个量 ⇒ 天然会漏掉未定义的形态

⇒ 【为什么不塞进本方案】：
   "防假阴性"要回答的是"什么算记忆、什么算漏掉了记忆"，
   属 prereg §2.2 的 MECHANISM CANDIDATE 层，
   而该层 prereg §38 标为 DEFERRED。
   ⇒ 这是凌翼四条底线之外的第二个、更深的问题，需单独立项。

⇒ 【按钳星意见，本方案只做一件事】：把它【写出来】，
   而不是沉默地漏掉。
   ⇒ 引用 prereg §39：「Not assessed is not not detected.

⇒ 【凌翼 2026-11-18 裁定三-d（三-a + 三-b 的有界组合）】：

   ① 假阴性【已登记为独立的未解决研究议题】
   ② 相关报告【必须显式声明】：
      「未检测到已定义的变化，不能推出任何可能的记忆机制都不存在」
   ③ 此次立项【仅授权】：
      · 问题定义
      · 适用范围
      · 测量灵敏度设计
      【不授权】开启新的科学实验
      【不要求】立即定义完整的记忆本体论
   ④ 可提出已知正控制、检测灵敏度、漏检风险的验证方法，
      但这些【只能评价特定测量器】，
      【不能证明】它能够发现所有可能的记忆形式。

     Not detected is not unresolved.」
     —— 这句话挡住"把没测写成没有"，但不回答"假阴性怎么测"。
✗ 是否存在主观体验/连续性（无任何已验证方法）
```
