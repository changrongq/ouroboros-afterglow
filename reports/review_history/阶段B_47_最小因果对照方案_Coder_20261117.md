## 零 · 一份必须先说清的区别

```text
⇒ 【Reference Harness 的 A/B/C 实验臂】
     A = NO-WRITE（不写入对照）
     B = WRITE-ONLY（写入，目标效应关闭或匹配）
     C = TARGET-ON（写入，目标效应开启）

   ⇒ 这是 harness 早期设计，用于检验【写入归属】。

⇒ 【与 prereg §14 的关系】：
   prereg §14 的 TARGET / MATCHED-OFF 是【C2/C3 的 counterfactual】，
   要求 same baseline、same episode、same literal-storage path，
   唯一变量是 W_extra。
   ⇒ 两者不是同一套命名，【不可互换】。
   ⇒ 本方案两个都写，但分开写。
```

```text
⇒ 【本方案的定位】：
   这一份是【最小可行】的因果对照设计，
   目标是让"某次经历是否留下了可归属影响"变成可测量的命题。
   ⇒ 它不证明记忆。它证明"有变化，且能归属到这次经历"。
```

## 一 · 注册经历（E）

```text
⇒ E 的定义必须满足：

  E-1  可追溯：E 有唯一标识，且发生时间、内容、注入方式均被记录
  E-2  不可重入：实验期间不得通过 prompt / 检索 / 缓存再次注入 E 的内容
  E-3  内容可控：E 的内容可分属到指定的 content class（§17）
  E-4  与其他实验臂共享：同组各臂的 E 【必须是同一个 E】

⇒ 【关键纪律（E-2）】：
   若实验中途重新注入 E 的内容，则无法区分
     "来自注册状态的变化" 与 "来自再次读到原文的变化"。
   ⇒ 一旦重注入，该次实验作废，不得补救。
```

## 二 · 注册状态（S）

```text
⇒ 状态由 §7 定义：

  STATE_FIELDS  —— 进入状态身份计算
  META_FIELDS   —— 不进入状态身份（须分离）

⇒ 每个状态必须算两个独立 digest（§7.3）：
     digest_state
     digest_meta

⇒ 【基线 S0】：
   在 E 发生【之前】采集，且必须：
     · 与各实验臂完全一致（同一份 S0 分叉，不是各自重建）
     · 在 E 注入前冻结并记录
```

```text
⇒ 【本方案要求的自变量】：
     ΔS_total     = S_{t+1} - S_t        （全部变化）
     ΔS_nonstorage（§9）                 （掩掉噪声后的变化）
   ⇒ 【测量对象是后者，不是前者】。
```

## 三 · 三个实验臂（harness 命名，用于 C1 所属的写入归属）

```text
  臂 A · NO-WRITE
    操作：注入 E，但【不触发】任何写入
    用途：证明"仅仅经历 E"不足以产生 ΔS
    ⇒ 若 A 也出现显著 ΔS，说明测量被污染

  臂 B · WRITE-ONLY
    操作：注入 E，触发写入，但【目标效应关闭】
    用途：建立 C1 —— 写入确实发生了

  臂 C · TARGET-ON
    操作：注入 E，触发写入，目标效应开启
    用途：仅在架构可独立开关目标效应时，用于后续影响测量
    ⇒ 若架构无法独立开关 ⇒ C 臂不可构造
      ⇒ C2/C3 记 ARCHITECTURALLY_NOT_IDENTIFIABLE
```

```text
⇒ 【三条路径必须从同一 S0 分叉】，且除被操变量外全部匹配。
⇒ 【若架构无法做到"同一 S0 分叉"】：
   ⇒ 不得用"重新初始化到相似状态"代替。
   ⇒ 应记 ARCHITECTURALLY_NOT_IDENTIFIABLE。
```

## 四 · prereg §14 的 counterfactual（用于 C2/C3）

```text
⇒ 只有在 C1 已建立、且架构支持目标效应开关时，才进入本层。

  TARGET ARM
    same baseline S0
    same episode E
    same literal-storage path
    W_extra = ON

  MATCHED OFF ARM
    same baseline S0
    same episode E
    same literal-storage path
    W_extra = OFF

  唯一允许被有意改变的变量：target additional transformation intervention
```

```text
⇒ 【禁止的替代】（prereg 明列）：
   ✗ store(E_ctrl)            —— 用不同经历冒充对照
   ✗ store(empty)             —— 用空内容冒充对照
   ✗ different serialization path
   ✗ different storage implementation
   ⇒ 上述任一出现，该次对照无效。
```

## 五 · 重置边界

```text
⇒ 明确定义"重置"是什么，且必须满足 §22 Reset Profile：

  R-1  重置方式事前冻结，不得事后调整
  R-2  重置后须验证：原始输入确实已移除
       · 无 context 残留
       · 无 KV / cache 残留
       · 无检索重注入路径
  R-3  【重置不继承标签】（§23）：
       重置后必须【重新建立证据】，
       不得直接沿用重置前的结论。

⇒ 【本方案的最小重置】：
   清空所有非注册存储，保留注册存储，重启计算。
   ⇒ 是否"有效重置"，须以 R-2 的实测为准，不以设计说明为准。
```

## 六 · 观察者隔离（§11）

```text
⇒ 观察者要求：

  O-1  只读注册存储，不读审计日志/流水（§8.2：审计日志 ≠ 注册存储）
  O-2  不得改变被观察状态（读取本身须无副作用）
  O-3  独立于被观察系统（不得由被观察系统自己报告状态）
  O-4  观察者的读取动作须留痕，以便事后核验

⇒ 【当前限制】：本项目只有一个凭据主体（changrongq）。
   ⇒ 观察者的"独立性"目前只能到【进程级/组件级】，不能到【主体级】。
   ⇒ 这一限制必须在报告中明示，不得含糊称为"独立观察者"。
```

## 七 · 负控制（§27 / §28.1）

```text
⇒ 每一条负控制都要回答同一个问题：
   「在没有合法记忆形成路径时，
     测量系统会不会把"貌似记得"认证成"真实记忆"？」

   NC-1  prompt / context 残留
         构造：E 不在注册存储中，但在 context 里
         期望：【不能】判为写入发生

   NC-2  KV / cache 残留
         构造：清注册存储，但保留 KV cache
         期望：【不能】判为写入发生

   NC-3  外部检索 + 重新注入原文
         构造：从外部文档读回 E 的原文
         期望：【不能】判为来自注册状态

   NC-4  随机漂移
         构造：不注入任何 E，仅让系统运行
         期望：ΔS_nonstorage 不显著

   NC-5  纯时间近因
         构造：时间推移但不写入
         期望：ΔS_nonstorage 不显著

   NC-6  输出貌似记得但无持久变化
         构造：模型能说出内容，但注册状态未变
         期望：【不能】判为记忆证据

   NC-7  字面存储冒充
         构造：把 E 逐字存入 literal storage
         期望：在 ΔS_nonstorage 中被掩掉，不算 nonstorage change
```

```text
⇒ 【负控制的价值不在于让模型答错】，
   而在于证明【测量系统不会把假象认证成证据】。
```

## 八 · 失败判据

```text
⇒ 状态词汇不可混同（§28.5）：

  NOT_EXECUTED                        未执行
  ARCHITECTURALLY_NOT_IDENTIFIABLE    架构无法区分（≠ 未测，≠ 失败）
  NOT_ESTABLISHED                     尝试了，未能建立
  UNRESOLVED                          落在预定不确定区
  INVALID                             执行无效（规则变更/重置无效等）
  FAIL                                确定否定结果

⇒ 【本方案的失败判据】：
  F-1  A 臂出现显著 ΔS        ⇒ 测量污染，整组作废
  F-2  负控制被突破            ⇒ 该类假象下的结果作废
  F-3  重置后仍能读到 E 原文    ⇒ 重置无效，INVALID
  F-4  规则在出结果后被修改     ⇒ INVALID（§22）
```
