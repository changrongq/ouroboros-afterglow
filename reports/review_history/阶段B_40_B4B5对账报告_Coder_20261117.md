```text

   并标成 ✅ 已验证。

⇒ 【这是错的】。
   git 的 author 字段来自本地配置：
     user.name  = Coder
     user.email = coder@local

     不是"谁持有推送凭据"。

⇒ 一个正确的证据应当是：
     git credential fill → username = changrongq
     GET /user           → login    = changrongq

⇒ 【这个错误和之前的"C-3 把字段存在当成证据成立"是同一类】：
   我把"有一个名字"当成了"有一个可证明的主体"。
```
