## 2. Q3-F1 修法（V2）

- `start_run()` 生成**每轮 run secret**（32B）+ nonce。
- `probe_read_access()` 是**唯一**能封 witness 的入口：对 observed 字段做 `HMAC-SHA256` 封条写入 `seal`。
- `AccessWitness.isolated` 现要求：`seal` 有效（`hmac.compare_digest`）+ `attempted is True` + verdict∈{DENIED} + 绑定 identity + `attempted_path==abs_path`。
- **手工构造 / 篡改封条 ⇒ isolated False**（实测）。

```text
[PASS] SEAL: genuine denial witness is isolated
[PASS] Q3-F1: hand-forged witness (no seal) -> isolated False
[PASS] Q3-F1: tampered seal -> isolated False
```

## 3. 四处证据缺口

### 缺口 1 · Restricted token ≠ 不同 user SID（**实测确认**）
```
CreateRestrictedToken(h, DISABLE_MAX_PRIVILEGE):
  normal   TokenUser.SID = S-1-5-21-2628700165-2029237996-3966631589-500
  restricted TokenUser.SID = SAME
```
⇒ 凌翼判断正确：靠 `TokenUser.SID` 加 deny 会把 controller 和 worker **一起拒**。
**正确形状（已实测）**：用 **restricting SID（`S-1-5-12`）** 加 deny ACE ⇒ **observer（无 restricting SID）仍可读（GRANTED）**。
```text
[PASS] SHAPE: deny by RESTRICTING SID -> observer still reads (GRANTED)
```

**诚实边界（重要）**：在**本机**（单账户、非提权）跨进程以受限 token 启动 worker 会失败——
`CreateProcessAsUserW` 子进程退出码 `0xC0000142`（`STATUS_DLL_INIT_FAILED`），需要 profile/window-station/提权。
⇒ **本机能证明"ACL 隔离形状"与"同进程认证 witness"，但无法证"完整跨进程受限沙箱"**。我不把它写成已完成的隔离。这与凌翼给的两条路一致：真正不同账户需凭证/权限，本机没有。

### 缺口 2 · Fresh-worker 生命周期（**已修**）
- 旧稿 `worker_start = time.time()` 在 `communicate()` **之后** ⇒ 记的是结束时间，不是创建时间。
- **V2**：用 `GetProcessTimes`（经进程 HANDLE）读**真实创建时间与退出时间**；要求 `old_exit <= new_create`（旧进程先于新进程终止）才置 `old_terminated_before_new=True`；无旧 pid 时**不声明**。
- `close_fds=True` 显式写入（必要非充分，已注明）。
```text
[PASS] LIFECYCLE: OS creation time recorded for new worker
[PASS] LIFECYCLE: old-before-new NOT claimed when no old pid
```

### 缺口 3 · 清理 ≠ 恢复原 DACL（**已修**）
- 旧稿 `icacls /reset` + 忽略 `acl_text` ⇒ 只是重建继承权限，不是精确回滚。
- **V2**：`icacls /save`（捕获**完整 SDDL**）→ `icacls /restore`（精确还原），**返回码必查**。
```text
[PASS] DACL: exact restore via saved SDDL verified
```

### 缺口 4 · 对象身份未参与判定（**已修**）
- 旧稿 `bind_object_identity` 记了 size/sha256 但 `isolated` 没用。
- **V2**：`seal` 覆盖 `abs_path/size/sha256`；并新增 `identity_still_matches()` 供 controller 侧核对。
