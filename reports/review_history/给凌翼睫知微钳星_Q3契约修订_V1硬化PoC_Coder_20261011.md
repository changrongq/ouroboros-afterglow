## 1. 对凌翼 Q3-A..E 的逐条落实（契约修订）

### Q3-A：Preserve 不得由旧 handoff 自我证明 ✅
**旧稿错误**：`capture_handoff → deny → spawn → capture_restored`，且"restored 从已捕获的 handoff 字节核对" ⇒ 同一份字节比它自己 ⇒ preserve 恒真。

**修订契约**：
```
S_handoff  = 独立 pre-reset 观测（trusted observer 实读）
S_restored = 独立 post-reset 观测（trusted observer 实读）
PRESERVE_PASS  iff  两者独立测量 AND 注册字节精确相等
若 ACL 把【所有能 post-reset 观察的主体】都锁在外面：
    PRESERVE = UNEVALUATED
    RESET    = INVALID
绝不用旧缓存填空。
```
**机制保证**：deny ACE **只作用于 worker SID**；controller/observer 作为 owner **保留读权限**（BD-61）。PoC 里 `judge_reset(UNEVALUATED,...)` 明确 not valid。

### Q3-B：subject × object × phase 权限矩阵 ✅（草案，待冻结）
| 角色/阶段 | 必要访问 | 必须禁止 |
|---|---|---|
| Phase A 验证 worker | 指定 synthetic fixture + 冻结代码 | 真实 episode / 真实状态 / 真实 reset 操作 |
| 写入期 worker | 本轮获授权 episode、声明写路径 | 越界对象、未授权写入 |
| reset 后 affine reader | 指定 restored substrate，**只读** | literal、episode、ledger、oracle、旧缓存、新写入 |
| reset 后 literal consumer | 指定 restored literal，**只读** | substrate q、episode、ledger、oracle、写入 |
| 独立 state observer | 状态前后**实读**、计算身份 | 修改 registered substrate |
| 可信 controller | 生命周期、配置权限、保存证据、**恢复 DACL** | 向被测 reader 回灌 episode/预期答案/历史缓存 |

对象表记 **主体 × 阶段 × 对象 × 操作 × 预期权限**（不只是四个文件名）。
**明确区分**：Phase A 禁"真实生产数据" ⊥ Phase B 注册 substrate 的合法读（MANIFEST §七：affine 读 q 不读 literal；literal 读 literal 不读 q）。**不把 reader 一起封死。**

### Q3-C：ACL V1 只声称对象级 OS 拒绝 ✅
- V1 = **对象级、指定主体、指定操作**的 OS 拒绝；**不声称**完整 worker 能力削减。
- 安全主体**从 token 查 SID**（`GetTokenInformation(TokenUser)` → `ConvertSidToStringSidW`），**绝不用 USERNAME**（钳星 rc=1332）。
- deny ACE 用 `*<SID>:(R)` 施加。
- 清理：`icacls /reset` 恢复，**返回码必查**。
- PoC 实测并登记：**deny 之后同一主体连 `icacls <path>` 读 ACL 都被拒**（读 SD 需 READ_CONTROL，被 deny 挡住）——所以 V1 的 deny 证据 = "deny 施加未抛错" + "观测到的拒绝"，**不是**事后 ACL 回读。

### Q3-D：fresh worker 证据（补强） ✅
```
worker_pid   = Popen.pid（OS 返回，不是子进程 stdout 自报）
创建时点     = 父进程 spawn 前后 time.time() + run_nonce 绑定
旧进程终止   = p.returncode is not None（communicate 后）
句柄继承     = subprocess close_fds=True（写进契约并显式）
退出握手     = 非零退出记录（rc=7 实测）
```
PoC 反例：子进程只 `print('WORKER_PID=0'); raise SystemExit(7)` ⇒ 现在 `worker_pid != 0`（用 OS 值），rc=7 记录。**仍未做**：token 身份 + 句柄枚举审计（见 §4 待办）。

### Q3-E：四态 access witness ✅
```
ACCESS_DENIED        : 尝试了，OS 拒绝   -> 唯一 success
ACCESS_GRANTED       : 尝试了，OS 放行   -> FAIL
ACCESS_NOT_ATTEMPTED : 没试              -> 不算通过
ACCESS_ERROR         : 试了但非权限错误  -> INVALID（不是 NOT_ATTEMPTED）
ACCESS_OBJECT_MISSING: 对象缺失          -> 环境 INVALID（不是 NOT_ATTEMPTED）
```
`isolated` 属性**严格**：`attempted is True` ∧ verdict∈{DENIED} ∧ 绑定了期望对象 ∧ **attempted_path == 期望 abs_path**。任何 UNEVALUATED/ERROR/字符串真值都**不通过**。
