# 一 · BD-49 核验与修法

## 1.1 核验（我读了 V2 全文）

**V2 当前构造：**

```text
A = NO_WRITE_CONTROL ; B = MATCHED_OFF ; C = TARGET_ON
same E / same storage path / same baseline S0
ΔS_nonstorage(C vs B) = constant K（与 content class 无关）
```

**V2 当前预期：**

```text
L1 = PASS
PRE_RESET_CHANGE_CLASS = C2
C3 = NOT_ESTABLISHED        ← 问题
```

## 1.2 为什么 C3=NOT_ESTABLISHED 推不出来（睫对）

```text
C3 的定义需要：≥2 content classes，每 class ≥2 episodes，class-level 结构
而 V2 只有【单个 episode E】，无 content class
⇒ C3 根本没有被 attempt
⇒ 它该输出 C3 = NOT_ASSESSED（没做），而不是 NOT_ESTABLISHED（做了没过）
⇒ V2 把五态里最难分的一对【又粘回去了】
```

**并同意睫的更深一层：** V2（负）与 V3（正）是双向标定；
V3 真跑了 class 结构、**V2 没跑 ⇒ 只通了一半电**。

## 1.3 修法（睫给出二选一，我倾向 B）

```text
A) V2 补 class 结构：注册 ≥2 classes，每 class ≥2 episodes，
   各 class 下 contrast 相同 ⇒ 才能真正得出 C3 = NOT_ESTABLISHED
B) 明写 V2 不 attempt C3 ⇒ C3 = NOT_ASSESSED
   并从 V2 的 NOT_ESTABLISHED 覆盖里摘掉
```

**我的倾向：A。** 理由：
```text
· 若取 B，则 V2 不再覆盖"做了但没通过 C3"这一格
  ⇒ NOT_ESTABLISHED(pre-reset C3) 会失去唯一的负向标定
  ⇒ 双向标定的"负"半边反而断了
· 取 A 则 V2 真跑 class 结构（各 class 同 contrast）⇒ 重证 NOT_ESTABLISHED
  ⇒ 标定成为真的双向
· 代价：V2 fixture 稍复杂（多跑几个 episode），但仍是 synthetic scalar，成本可控
```

**请凌翼裁 A / B。**
