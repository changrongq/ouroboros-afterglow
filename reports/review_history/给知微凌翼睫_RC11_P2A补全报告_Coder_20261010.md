## 1. P2-A 相邻分支闭合

**知微指出**：`evidence_bundle.py` 中身份检查的三个**提前返回**分支（`RESET_VERIFIED_MISSING` / `RESET_STORED_RESTORED_MISSING` / `RESET_VERIFIED_MALFORMED`）仍带出初始化默认值，导致 `preserve_rule_ok=True`（实际 preserve 尚未执行，应为 `UNEVALUATED`）。

**修法**：重写该函数，令**所有**身份阶段失败分支统一显式返回同一种形状：
```
(True, False, False, UNEVALUATED, code)
```
不再依赖初始化值或跨 arm 的残留状态。

**复现（知微原样三条）**：
```
case1 missing verified_restored   -> reset_identity_ok=False | preserve_rule_ok=UNEVALUATED
case2 partial (缺 q_raw)           -> reset_identity_ok=False | preserve_rule_ok=UNEVALUATED
case3 malformed (q_raw='zz')       -> reset_identity_ok=False | preserve_rule_ok=UNEVALUATED
clean V5a                          -> reset_identity_ok=True  | preserve_rule_ok=True
```
对照仍正确：纯 preserve 违例（身份相符）→ `reset_identity_ok=True, preserve_rule_ok=False`。
