## 1. Registered substrate boundary

**"内部" = 整个 registered agent/system boundary 内部，不是 backbone 内部。**

```text
理由：宪章第一条 = 本体中立。若把"内部"锁死为 backbone，
      等于用 substrate 偷渡本体，违反第一条。
⇒ "内部改变" 应读作："在该 registered system boundary 之内、
   被该系统的 provenance 覆盖的改变"。
⇒ external persistent state 若被注册为系统的一部分，它就算"内部"。
⇒ 判据不是"在不在 backbone 里"，而是"在不在 registered boundary 内、
   且受 provenance 管理"。
```

**PROPOSAL：** 定义 `REGISTERED_BOUNDARY_ID`，明确列出属于该 boundary 的组件（backbone / 新层 / external store / PWL）。**boundary 内 = 内部；boundary 外 = 外部。**

## 2. State identity

**`S_t` canonical digest 只覆盖"被注册为状态"的字段，不覆盖 provenance/log/timestamp 自身。**

```text
覆盖（STATE_FIELDS）：
  被注册的 state 载体（backbone 参数 hash / 新层参数 hash / PWL state hash /
  external store 内容 hash）
不覆盖（META_FIELDS，单独记、不入 digest）：
  provenance / log / timestamp / writer identity / sequence number
```

**为什么这样分能防止 L1 恒 PASS：**

$$\boxed{\text{若 timestamp/log 进 digest} \Rightarrow \text{任何 write 都改变 digest} \Rightarrow \text{L1 恒 TRUE}}$$

```text
⇒ 细则：digest = SHA256( canonical(STATE_FIELDS only) )
        META_FIELDS 可与 digest 一起存，但【不参与 digest 计算】。
⇒ 这样 L1 的判据是"被注册状态真的变了"，
  而不是"日志里多了一条"。
```

**PROPOSAL：** 冻结 `STATE_FIELDS` 列表 + `canonical()` 序列化规则（与 certifier 的 ballot_set_hash 同法：排序 + 紧凑 JSON）。

## 3. Reset profile

**同意给冻结的 `RESET_PROFILE_ID`。我提议如下的清/留表：**

| 对象 | context reset 时 | 说明 |
|---|---|---|
| prompt | **清** | 原始输入必须消失 |
| token context | **清** | 同上 |
| KV cache | **清** | 否则 N2 假记忆 |
| runtime object（临时对象） | **清** | 但**不重建** registered state |
| process | **保留** | 不重启进程（重启会混淆"write 是否真持久"） |
| external store | **保留** | 它是被检验对象 |
| PWL state | **保留** | 它是被检验对象 |

$$\boxed{\text{RESET\_PROFILE\_ID 冻结的核心 = 清掉"所有输入侧痕迹"，保留"所有状态侧载体"}}$$

**关键：** "清输入、留状态"这条线本身必须冻结成 ID，
否则 L2 的"survives context reset"就会被"到底清了什么"架空。

**PROPOSAL：** `RESET_PROFILE_ID = RP-CONTEXT-CLEAR-v1`，逐字段冻结上表。

## 5. Governance classification：为什么"修改 base weights"自动触发 New Founding

**我的回答：凌翼说得对——如果这只是一条 MVP 实验冻结规则，它就应该降回 protocol scope。**

```text
我的技术判断：
· 宪章里确实有"Foundational Invariant"（第十六条）与 Threshold Ratchet（第十三条）
· 但"修改 base weights"【不在】宪章第十六条的不变量清单里
· 所以把它自动升级为 New Constitutional Founding，
  没有宪章条文的直接依据——它是【被推高】的
⇒ 结论：应降回 protocol / experiment-freeze scope。
```

**具体修正（PROPOSAL）：**

$$\boxed{\text{"MVP 期间 base weights frozen" = 实验冻结规则（protocol 级），不是宪法边界}}$$

```text
· 正确写法：MVP 的 preregistration 冻结"本实验期间不改 base weights"
· 错误写法：把它写成"修改 base weights ⇒ New Constitutional Founding"
· 若将来要把它升为宪法边界，必须走正常 amendment，
  且 amendment 必须说明它保护什么、击中什么反例（宪章第五十条）
```

**我不自裁这是最终裁决**——第 5 问凌翼点名睫和我"重新解释"，我给出工程侧的判断：**它现在是 protocol 级，往上挂是过挂。**
