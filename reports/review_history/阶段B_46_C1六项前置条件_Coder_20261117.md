## 一 · C1 的定义边界（先划清）

```text
⇒ prereg §12 C1 = `STORAGE_WRITE_ESTABLISHED`

   表示：storage write 是目前【最高被正向建立】的 change class
   不表示：reality contains only storage change

   最强允许 claim：REGISTERED_STORAGE_WRITE_OBSERVED
   ⇒ 【C1 是证据断言，不是世界断言。】
```

```text
⇒ 【因此 C1 通过也不能推出】：
   ✗ 记忆已形成
   ✗ 该变化会影响未来行为
   ✗ 变化跨重置保持（那是 L2）
   ✗ 有意义的记忆 / 长期保持 / 主观连续
```

## 四 · 关于 Reference Harness 的严格限制

```text
⇒ 【允许用它做什么】：
   · 验证测量流程能跑通（管道测试）
   · 验证失败判据会触发
   · 验证负控制能否拦住合成假记忆

⇒ 【禁止用它做什么】：
   ✗ 用它的结果补填 P1～P6 的"已验证"
   ✗ 用它的 PASS 声称真实候选架构成立
   ✗ 用它的数据计算任何科学结论

⇒ 【理由】：合成环境里，"写入"是我们自己造的，
   ⇒ 它证明的是"我们能造一个可被测量的写入"，
   ⇒ 不是"这个架构会因经历而产生写入"。
```
