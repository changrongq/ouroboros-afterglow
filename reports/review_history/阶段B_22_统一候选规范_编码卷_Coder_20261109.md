## 四 · 规范化语义（唯一定义）

### 4.1 空集合（MAX_SCOPE_SET）

```text
⇒ 【条件（三字段合取，凌翼 #2 要求）】：
   · `element_count = 0`
   · `range_start_seq = 0`
   · `range_end_seq = 0`
   · `ELEMENTS` 长度为 0
   ⇒ 四条【同时成立】才是空集合。

⇒ 【哨兵禁用】：
   ⇒ 合法非空 seq 必须 ≥ 1（承 §2 与 §5 的 seq 语义）。
   ⇒ 故 `0` 只作哨兵，【不得】出现在非空集合里。
```

### 4.2 集合元素编码

```text
⇒ 元素字节 = `seq(8, BE)` ‖ `epoch(8, BE)` ‖ `record_digest(32)`
⇒ 按 `seq` 【升序】，无重复 seq。
⇒ 只含【已提交分配】，不含 PENDING、不含被排除者。
⇒ `record_digest` 必须是该 N2 记录的摘要。
```

### 4.3 初始根与首条记录

```text
⇒ 【凌翼三节 + 知微 的合取要求】：

   | 场景 | 字段 | 值 |
   |---|---|---|
   | 首条 HWM | `predecessor_hwm_digest` | 32 字节全零 |
   | 初始 EHWM | `event_hwm_value` | 0 |
   | 初始 EHWM | `last_event_digest` | 32 字节全零 |
   | 初始 EHWM | `ehwm_epoch_counter` | 0 |
   | 初始 EHWM | `predecessor_ehwm_digest` | 32 字节全零 |
   | 首条 0x8A | `predecessor_event_digest` | 32 字节全零 |

⇒ 【关键约束（知微）】：
   · 【不得单凭某个字段为零】就认定合法初始化。
   · 必须【合取检查】：类型、TAG、长度、域、世代、来源、
     以及"合法初始化事实"本身。
   · 【若已存在历史却缺失根】⇒ 按既有缺失/不可验证规则 ⇒ STOPPED。
     【不得】重建空根让历史看起来干净。

⇒ 【知微 对"消除特例"的更正，我接受】：
   初始 EHWM 自身仍用 value=0 / last=0 / counter=0 / 前驱=0。
```
