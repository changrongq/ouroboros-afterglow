## 2. Q3-F2/F3/F4 关闭（`afterglow_harness/q3_reset_chain.py`）

### Q3-F2 · STALE VERDICT + WAIT STATUS
- 检查 `WaitForSingleObject == WAIT_OBJECT_0`（否则 `TerminateProcess` + FAIL）。
- 检查 `GetExitCodeProcess` 成功且 `!= STILL_ACTIVE`。
- verdict 文件**绑定本轮 nonce**（探针脚本内嵌）；`NONCE=` 不匹配即拒；启动前**删除旧 verdict**。
- 反例：伪造 `NONCE=deadbeef` 的 stale 文件 ⇒ `verdict_matches_nonce=False`。

### Q3-F3 · TOKEN IDENTITY
- 经 `CreateProcessWithLogonW` 返回的进程句柄 `OpenProcess` → `OpenProcessToken` → 读 `TokenUser.SID`。
- 断言 **worker SID ≠ controller SID**。
- 绑定 `(SID, PID, 创建时间, run nonce, exit)` 成一份 process witness。

### Q3-F4 · 抗伪造拒绝
- 探针是**固定、可信代码**；记录其 **SHA-256**。
- controller 绑定 `(操作, 目标 path + sha256, OS 错误, nonce)`；verdict 必须匹配本轮 nonce 且目标一致。
- 与 observer 的对照读交叉印证（可归因拒绝）。

## 3. 端到端 reset 链（凌翼要求的完整序列）

```
trusted observer 读 S_handoff
  -> deny（只锁 worker；observer 保留读）
  -> 生成 bound probe（固定代码 + 目标 sha + nonce）
  -> spawn 跨账户 worker（attested：WAIT/exit/SID/nonce）
  -> controller 验证本轮 OS 拒绝证据
  -> observer 独立读 S_restored
  -> clear / preserve / access 三向判决（严格 is True）
```
