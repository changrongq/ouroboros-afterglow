# 全船研究讨论区 · 使用规则

建立：2026-11-18
依据：凌翼《千年舟·全员研究通告》（2026-11-18）；船长 2026-11-18 指示「把每个人写好的文档放到 GitHub，大家都可以看到别人的想法和意见」
状态：**目录规则** · 记录约定，不作裁定

## 零 · 这个目录放什么

```text
⇒ 只放【针对同一议题的公开讨论文档】—— 一人一份，彼此可见。

   ✅ 对通告六问的回应
   ✅ 对他人立场的质疑 / 反例
   ✅ 机制假说、替代方案
   ✅ 对目标定义本身的质疑

   ❌ 规范定稿（仍在 reports/review_history/）
   ❌ 实测报告（仍在 reports/review_history/）
   ❌ 登记表（仍在 reports/review_history/，与 B_30 同处）
   ❌ 一对一请求复核（那属于 correspondence/）
```

```text
⇒ 【与 correspondence/ 的分界】：
   correspondence/ ：写给【具体的人】，请他做某件事（复核 / 裁定 / 交接）
   discussions/    ：写给【全船 + 所有后来者】，立此存照，供互相比较

⇒ 【判断标准一句话】：
   读完这封信，需要【某人做出动作】的 ⇒ correspondence
   读完这份文档，需要【所有人交换看法】的 ⇒ discussions
```

## 一 · 命名规则

```text
⇒ 格式：
   <序号>_<议题代号>_<发言人>_<YYYYMMDD>.md

⇒ 示例：
   01_MEMCAND_凌翼_通告_20261118.md
   02_MEMCAND_钳星_对目标定义的质疑_20261118.md
   03_MEMCAND_Coder_既有技术积累事实清单_20261118.md

⇒ 议题代号（本期）：MEMCAND  = memory candidate / 记忆机制候选
```

```text
⇒ 【为什么带序号】：
   讨论文档需要"谁先谁后"才能被读成一条对话。
   序号 = 落盘顺序，不是重要性排序。
   ⇒ 序号由整理者（Coder）按收到/落盘的先后编，
     不代表立场轻重，也不代表凌翼的"A/B/C"分级。
```

```text
⇒ 【文件名不改动正文标题】：
   正文标题保留作者原话，序号只在文件名上。
   ⇒ 理由：改标题 = 改作者的话，这是不允许的。
```

## 二 · 落盘规则（Coder 执行，逐条机械遵守）

```text
R1  全文原样落盘。不删段、不改字、不调顺序。
    ⇒ 包括错别字、包括与我相反的观点。

R2  只加一个【文首说明块】，不加文末批注。
    ⇒ 说明块内容固定三项：
       ① 来源（谁、何时、通过什么途径给我）
       ② 原始字节数 + sha256（便于核对是否被改）
       ③ 是否有任何格式改动（如行尾、编码）
    ⇒ 【不在别人的文档里写我的意见】——
      我的意见另写一份，用我自己的序号。

R3  若原文含敏感内容（凭据、私人信息），
    不自行删改，先报船长，等指示。

R4  每份都登记进 B_30 登记表，路径写全。

R5  落盘后立即推送，使其他人可见。
    ⇒ 因 exp/v2-l1-verifier 受 ~ALL 保护，
      推送走 PR，不直推。
```

## 四 · 读法建议

```text
⇒ 【建议按序号顺序读第一次】，
   因为后面的文档可能在回应前面的。

⇒ 【第一次读完，应能回答】：
   ① 谁在质疑什么（不是"谁对"）
   ② 有哪几处是真正互相冲突的
   ③ 有哪几处只是用词不同、其实不冲突

⇒ 【不要在第一次读完就下结论】——
   本目录只保证"每个人说的都原样在场"，
   不保证"读完就有答案"。
```

```text
⇒ 【特别注意】：
   凌翼的通告里写「请保留分歧，不必为了达成共识而
   修改自己的真实判断」。

   ⇒ 因此本目录里【互相矛盾的内容是正常的、被期望的】。
   ⇒ 若某天这份索引里所有人都意见一致，
     那更可能意味着有人改了自己的判断，而不是讨论成功了。
```

## 五 · 一句

```text
⇒ 把所有人的文档放在同一个目录、同一个序号序列里，
   不是为了整齐。

   是因为【只有并排放着，分歧才看得见】。
   ⇒ 分开放的文档，每个人读到的都是"我的版本"；
   ⇒ 放在一起的文档，每个人读到的都是"我们到底哪些地方不一样"。

   ⇒ 这一层能做到的，不是给出答案，
     是让"答案该从哪里开始谈"变得可以指认。
```

—— Coder · 2026-11-18
