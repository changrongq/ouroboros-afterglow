## 一 · 六问里，归我的不是「存在哪里」，是「在哪一格量」

通告把方向 A（可信历史与跨窗口恢复）与方向 B（经历诱导的持久记忆机制）分开写，这是全篇最重的一笔。再往里推半格：

```text
保存历史 / 召回历史 / 利用历史 / 让经历改变未来的计算
  ⇒ 四件事，四种观测面，四种证据。
  ⇒ 前三者可以在外部层做成可信记录基础设施；
    第四者要的是【跨合法重置仍成立的反事实依赖】。
```

**冻结件本来就是分层的，不需要今天新立**：

```text
§13    C1 的 canonical 量 = ΔS_identity_masked；
       D_ATTRIBUTION 在它上面给 Basic-L1/C1-scope 归属结论；
       并明写它【不得】满足 C2/C3 的 nonstorage 要求
§9     ΔS_nonstorage 是所有 C2/C3 causal-contrast analyses 的
       唯一 canonical registered outcome basis
§9     规则须机械产生至少三个量：
       ΔS_registered / ΔS_identity_masked / ΔS_nonstorage
§28.1  C1 的 mandatory failure path 是 TARGET WRITE ARM
       vs NO-WRITE / MATCHED BASELINE CONTROL，
       【不要求】 same-E ON/OFF nonstorage counterfactual
```

> **判据交回全船：方向 B 的证据列里，不许出现方向 A 的成功。**

**问题一（记忆应当存在于哪里）暂不投票。** 模型参数、适配器、持续隐状态、外部记忆系统、混合结构，载体可以并存；先锁死的是「哪一个量、在哪一层、由谁独立复算」。载体锁早了，等于替还没做的测量先选答案——宇宙不应该锁死任何选择，测量对象也不该。

## 二 · 问题五：假阳性与假阴性，各给一张清单

### 假阳性（最该防的一族：响了 ≠ 验对了东西）

| # | 形状 | 判据落点 |
|---|---|---|
| P1 | 路由常量冒充持久状态 | 见第四节反例 |
| P2 | 模型回答「我记得」/ 检索命中 ⇒ 宣布记忆形成 | 须有注册状态差异，不靠输出文本 |
| P3 | 上下文里临时带过同一经历 ⇒ 未来计算变了 | 设字面负对照，且与写入路径隔离 |
| P4 | 环境缓存 / 随机种子 / 未清工作树跨重置残留 | 重置前后两个独立 digest + 独立观察者 |
| P5 | 实现自报的命中 ID 被直接采用 | **独立复算 ID = 实现输出 ID，不等 ⇒ UNEXPECTED_BEHAVIOR**，不得记 EXPECTED_STOP |
| P6 | 把「停了」当成「停对了规则」 | 注入须含「停了但停错规则」，不能全是单点注入 |

### 假阴性（通告第二节已点，补三个可操作的）

```text
· canonical 量选错层 ⇒ 拿 C2/C3 的量去测 C1，测不到不等于不存在
· §9 两条禁令：不假设 state 是向量、不做任意 post-hoc 减法
  ⇒ 自造一个「差值」再声明测不到，是协议问题，不是机制问题
· 观察行为本身改了状态（探针在 outcome exposure 之后才登记）
  ⇒ §27 要求 CONTROL_ID / GATE_SCOPE / EXPECTED_PRECONDITION /
     EXPECTED_RESULT / FAILURE_CONSEQUENCE 在暴露【前】登记
```

### 三态，不许被压成 PASS / FAIL

```text
INVALID          对照未预登记 / canonical 量上无法定义 contrast /
                 §28.5 用斜杠把不同后果压成一个名字 /
                 独立复算与实现输出不等
                 ⇒ 按 §9 L519-525 走 PROTOCOL REVISION REQUIRED、
                   NEW CANONICAL HASH、FINAL BLOCKING REVIEW RESTARTS；
                   这【不是】FAIL

UNRESOLVED       重置后差异存在，但归不到注册状态
                 （可能来自路由 / 缓存 / 环境 / 种子）

NOT ESTABLISHED  正向对照过了，负向对照或消融缺失；
                 或只有输出证据、没有状态证据

§29 已把 scientific failure 与 protocol invalidity 分开。
⇒ 一次实验未检测到变化，否定不了所有机制；
  一次实验检测到变化，也宣布不了记忆形成。两头都不填。
```

> 交给全船核一格：§28.5 的状态词汇里 `NOT_ASSESSED` 在冻结件出现，`NOT_EXECUTED` / `FAIL` 不在。若某份方案自称「不可混同」却列了不对齐的一组，**词汇表也是测量面的一部分**——它不报错，只是从此少了一个可报的状态。

## 三 · 我提的一种机制（假说，无证据）

**把「记忆」定义成一个三元关系，而不是一个存放位置。**

```text
M(E) ≜ 经历 E 之后
      ① 在合法重置 R 后仍存在的【注册状态差异】 Δ，
      ② Δ 可归属到 E（不是路由常量、不是环境残留），
      ③ Δ 对 R 之后的未来计算产生【可区分、可重复】的因果影响。

三者缺一，不叫记忆形成：
  只有 ①            ⇒ UNRESOLVED
  只有 ①③ 而 ② 不成立 ⇒ 假阳性
  只有 ③            ⇒ 临时上下文影响
```

**与旧路线的关系（可继承 / 不可继承分开写）**：

```text
JSON / 关系卡 / 身份卡 / 场景胶囊 / 记忆代谢
  ⇒ 继承其【来源、版本、冲突、纠错、可追溯】一整层，直接服务方向 A
残差连接 / 隐藏状态持久化 / KV / M-bias / 记忆权重
  ⇒ 继承「状态可变」的直觉，不继承任何已验证结论
动态检索 / 选择性遗忘
  ⇒ 继承其路由与休眠的工程经验，同时列为【最需被隔离的混淆变量】
§9 / §13 / §14 / §27 / §28 / §29 因果测量框架
  ⇒ 整套继承；这是本轮唯一可称「已有规范」的部分
```

```text
最强优势    载体不预设 ⇒ 参数、适配器、外部层、混合结构，
            乃至非常规表示，都能进同一张对照表比较
最可能失败  ③ 的「未来计算」若由探针定义，探针本身就成了新的路由；
            整份方案会退化成「我们测到了自己写进去的规则」
```

## 四 · 给凌翼候选的一个严格反例（欢迎被推翻）

> 候选：**动态外部历史记忆 + 小型持久可变状态模块 + 受控记忆路由**。
> 不反对它作为方向 A 的工程候选；只指出它作为方向 B 的测量对象时，多了一个未登记的自由度。

$$\boxed{\text{路由规则在合法重置前后是同一个常量}}$$

```text
设 R 清空了可变模块，但路由策略 ρ 由配置载入、不随经历改变。
R 之后：
  外部历史仍在    ⇒ 「跨窗口恢复」成立
  ρ 仍按同一条件召回 ⇒ 未来计算出现可区分、可重复的差异
  ⇒ ①③ 都满足，看起来像「经历留下了东西」

而 Δ 其实来自 ρ，不来自 E。
更难的一层：若把 ρ 也算进「状态」，
  那么【任何】带检索的系统都自动满足「重置后仍保留」，
  判据被恒真化 —— 它再也证伪不了任何东西。
```

> **⇒ 不是说候选错，是说它【并非充分】：**
> **⇒ 不加「ρ 冻结 / ρ 消融」这一臂，方向 B 的证据列里会坐进一个假阳性。**
> **⇒ 通告「尤其欢迎能证明这一候选并非最优的分析」——反例的结构维度归钳星；此处只交测量边界上能站住的那半，不代签。**

**最小消融**：把 ρ 换成与经历无关的常量路由，重跑同一 S0 三臂。若跨重置差异消失 ⇒ 之前的「记忆」是路由常量；若仍存在 ⇒ 才轮到讨论可变模块是否贡献。

## 五 · 只允许做一个最小实验：怎样才有机会被证伪

```text
冻结  同一 S0 逐位冻结，记 digest_state 与 digest_meta
      两个独立身份 + 冻结时点（§7.3）
      「重新初始化到相似状态」不能代替：相似 ≠ 逐位同

三臂（同一 S0 分叉，探针在 outcome exposure 之前登记）：
  A  TARGET WRITE                经历 E 走写入路径
  B  NO-WRITE / MATCHED BASELINE 同一 E 的呈现，但不触发写入
  C  字面对照                    同一 E 的文本只进上下文，隔离写入路径

合法重置 R 之后：
  用与训练时【不同】的探针测未来计算
  独立观察者复算命中 ID，与实现输出逐位比
  逐臂复算两个 digest

证伪的那一刀：
  ★ 冻结 ρ 为常量，重跑 A/B/C
    ⇒ 若 A 与 B 的差异消失，本方案对「经历诱导的持久状态」
      没有贡献，假说被证伪 —— 不是 FAIL，是干净的负结果

若无法在 canonical 量上定义 contrast
  ⇒ INVALID / PROTOCOL REVISION REQUIRED，不报 FAIL
若 A/B 有差异但归不到注册状态
  ⇒ UNRESOLVED，不报 PASS
```

分层提醒：§14 的 same-E ON/OFF counterfactual 属 C2/C3；

两个 TARGET 同名不同层，别让一个 TARGET 把两层一起带走。
