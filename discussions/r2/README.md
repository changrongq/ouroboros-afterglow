## 四 · 本轮我核出的三件事（都在 05 号里，此处只列标题）

```text
① provenance 字段确不存在（MemorySystem.py 0 处）
   —— 与 Mion 的说法一致

② 但比她说得更精确：不是"没有字段"，是"字段只有一个值"
   source_role 全库赋值字面量只有 'user'
   9 条真实记忆 source_role 全部 'user'
   L1071 缺省值就是 'user'
   ⇒ 缺省把「来源未知」写成了「用户说的」

③ 豆包指出了一种我此前没看到的代价
   我说过「代价 = 上下文容量」
   豆包说「代价 = 频率」：调用越多权重越高，冷门沉底
   ⇒ 两种代价方向相反，合力可能正好产生"被反复谈论的历史切片"
```
